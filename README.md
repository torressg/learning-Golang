# Learning Go

My notes and exercises from studying Go, one folder per topic.

| Folder | Topic |
| --- | --- |
| `1 - packages` | Packages, modules and an external dependency |
| `2-Variables` | Variables and constants |
| `3-DataTypes` | Data types |
| `4-Functions` | Functions |
| `5-Operators` | Operators |
| `6-Struct` | Structs |

Run any topic with `go run <folder>/<file>.go`. For the packages example, `cd "1 - packages" && go run .`.
